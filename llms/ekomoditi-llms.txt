# eKomoditi

> eKomoditi (PT Ekomoditi Solutions Indonesia) is a Southeast Asian agriculture-technology company, founded 2015 in Jakarta, that builds digital plantation-management software for oil palm, rubber, sugar, and durian estates. Its flagship Electronic Plantation Control System (ePCS) replaces paper-based field recording with a mobile in-field app, eGIS geographic mapping, mills automation, and business-intelligence analytics. eKomoditi does not currently publish a public developer API, SDKs, or API documentation.

## Products
- [ePCS In-field System](https://ekomoditi.id/products): Android application for real-time plantation data collection (harvesting, fertilization, pest management, worker, and transport data) enabling same-day reporting.
- [eGIS Mapping Application](https://ekomoditi.id/products): Geographic information system mapping tool for plantation estates.
- [Plantation Marketplace](https://ekomoditi.id/products): Commerce platform for plantations.
- [Mills Automation](https://ekomoditi.id/products): Processing-facility automation.
